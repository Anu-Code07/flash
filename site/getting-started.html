Getting Started

Install to hot reload in under 2 minutes.

1. Install

One command installs Rust (if needed), the Flash SDK, and the flash CLI:

curl -fsSL https://raw.githubusercontent.com/Anu-Code07/flash/main/install.sh | bash
source ~/.zshrc

Auto-create a demo app during install:

FLASH_QUICKSTART=1 curl -fsSL .../install.sh | bash

2. Verify

flash doctor

Checks Rust, CLI, SDK path, and optional iOS/Android tooling.

3. Create an app

flash create my_app
cd my_app

Scaffolds clean architecture:

my_app/
├── ui/screens/           # .ui files
├── crates/
│   ├── presentation/     # view models
│   ├── application/      # use cases
│   └── infrastructure/   # HTTP, storage
├── platform/
│   ├── ios/              # Xcode
│   └── android/          # Gradle
└── flash.toml

4. Run with hot reload

flash run

Reads flash.toml — edit ui/screens/home.ui and save. Changes apply in <1s.

5. Choose a device

flash devices
flash run -d simulator   # default preview
flash run -d native      # native command buffer
flash run -d ios         # UIKit (macOS + Xcode)
flash run -d android     # Android Views

Command cheat sheet

CommandWhat it does
flash doctorCheck toolchain and SDK
flash createScaffold a new project
flash runHot reload dev server

flash pub getFetch Rust workspace deps
flash upgradeUpdate SDK + CLI
flash build iosNative iOS build guide

Update later

flash upgrade

Troubleshooting

command not found: flash

Run source ~/.zshrc or reinstall with the curl command above.

SDK not found

Ensure FLASH_SDK points to ~/.flash/sdk. Run flash doctor.

From git clone

./scripts/install-flash.sh or cargo install --path cli --force

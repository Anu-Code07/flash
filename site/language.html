Language Reference

Flash .ui is a purpose-built declarative language for mobile UI. It is strongly typed, compiled ahead of time, and designed for fine-grained reactive updates.

Overview

Every .ui file contains screen, component, or use declarations. The compiler produces a flat UI IR and a static dependency graph.

screen Home { ... }
component UserCard(name: String) { ... }
use presentation::{FlightsViewModel, FlightsState}

Screens

A screen is a top-level UI entry point. It can accept injected dependencies (view models) as parameters.

screen Profile(vm: ProfileViewModel, userId: String) {
    onLoad { vm.load(userId) }
    Column { ... }
}

State — @provider

Riverpod-style providers with compile-time dependency tracking. No manual writes annotations.

@provider Counter {
    @state count: Int = 0
    @state high_score: Int = 0

    @action increment() {
        count++
        if count > high_score { high_score = count }
    }
}

screen Home {
    @inject counter: Counter

    Text("${counter.count}")   // auto-watch
    Button("+") { counter.increment() }
}

Simple screen-local state still works: state count: Int = 0 (sugar for @provider(scope: Screen)).

Full guide: State management docs

Components

component UserCard(name: String, age: Int) {
    Column {
        Text(name).font(size: 18, weight: .bold)
        Text("${age} years old").color(.muted)
    }

if / else

if loading {
    Loading()
} else {
    Text("Done")
}

match

Exhaustive matching on Rust enums imported via #[ui_export].

match vm.state {
    Loading         -> Loading()
    Empty           -> Text("No results")
    Error(msg)      -> Text(msg)
    Loaded(items)   -> List(items) key: item.id { item in
        ItemCard(item)
    }
}

List

Always supply key: for efficient keyed reconciliation (maps to UICollectionView / RecyclerView).

List(users) key: user.id { user in
    UserCard(name: user.name, age: user.age)
}

Modifiers

Chain modifiers for styling. Resolved at compile time into flat style records.

Text("Hello")
    .font(size: 20, weight: .bold)
    .color(.primary)
    .padding(16)
    .safe_area()
    .background(.surface)

Animation

Animate compositor-only properties via platform animators. Never animate layout properties.

Box()
    .opacity(visible ? 1.0 : 0.0)
    .with_animation(.ease_in_out(duration: 300))

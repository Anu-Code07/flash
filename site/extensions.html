Extensions

Flash extensions let you extend the language with custom modifiers, view models, and platform hooks — without forking the compiler.

Modifier extensions

Chain custom styling on any node. Extensions compile to flat style records in the IR.

// Define in a .uiext file or Rust crate
extension CardStyle on Column {
    fn card() {
        self
            .padding(16)
            .background(.surface)
            .border_radius(12)
            .shadow(radius: 4, opacity: 0.1)
    }
}

// Usage in .ui
Column { Text("Hello") }.card()

View model extensions

Export Rust structs to .ui with #[ui_export]. The compiler reads .uiapi manifests at build time.

// crates/presentation/src/counter_vm.rs
#[ui_export]
pub struct CounterViewModel {
    #[ui_export(read)]  pub count: i64,
    #[ui_export(read)]  pub high_score: i64,
}

#[ui_export]
impl CounterViewModel {
    #[ui_export(writes = "count, high_score")]
    pub fn increment(&mut self) {
        self.count += 1;
        if self.count > self.high_score {
            self.high_score = self.count;
        }
    }
}

Collection extensions

Extend STL collections with custom algorithms in Rust, callable from view models.

// stl extension — registered at compile time
extension List<Flight> {
    fn cheapest() -> Flight? {
        self.reduce(|a, b| if a.fare < b.fare { a } else { b })
    }

    fn by_airline(name: String) -> List<Flight> {
        self.filter(|f| f.airline == name)
    }
}

Animation extensions

Custom curves and transitions compile to platform animators — zero per-frame FFI.

// Built-in curves
.with_animation(duration: 300, curve: .ease_in_out)
.with_animation(duration: 500, curve: .spring(damping: 0.8, stiffness: 300))

// Custom extension
extension FadeTransition {
    fn fade_in(duration: Int = 400) {
        self
            .opacity(0)
            .with_animation(duration: duration, curve: .ease_out)
            .opacity(1)
    }
}

Navigation extensions

Routes are compile-time checked. Params are typed.

// routes.ui — generated route table
route Home
route Flights(query: String)
route FlightDetail(id: String)

// Usage
navigate("flights", { query: "SFO-LAX" })
navigate_back()

Design token extensions

Extend the theme with custom tokens. Tokens resolve at compile time.

// theme.flash.toml
[tokens]
brand = "#6366F1"
on_brand = "#FFFFFF"
card_elevated = "#F8FAFC"

// Usage in .ui
.color(.brand)
.background(.card_elevated)

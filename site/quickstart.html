Quickstart

Build your first Flash mobile app in 5 minutes.

1. Prerequisites

  • Rust 1.75+ (rustup update)
  • For iOS: Xcode 15+, macOS
  • For Android: Android Studio, NDK r26+

2. Install the Flash SDK (one command)

curl -fsSL https://raw.githubusercontent.com/Anu-Code07/flash/main/install.sh | bash
source ~/.zshrc
flash doctor

Installs Rust if needed, clones SDK to ~/.flash/sdk, adds flash to PATH.

3. Create your app

flash create my_app
cd my_app
flash dev          # reads entry from flash.toml

4. Run the Flash repo counter (optional)

cd flash
flash run examples/counter/home.ui
# or: cargo run -p flash-cli -- run examples/counter/home.ui

Expected output: one SetProp + one Commit on tap — fine-grained reactivity confirmed.

5. Project layout (clean architecture)

my_app/
├── ui/screens/           # .ui files
├── crates/
│   ├── presentation/     # view models → .ui
│   ├── application/      # use cases
│   └── infrastructure/   # HTTP, storage
├── platform/
│   ├── ios/              # Xcode
│   └── android/          # Gradle
└── flash.toml

6. Create a screen

// app/screens/home.ui
screen Home {
    state count: Int = 0

    Column {
        Text("Count: ${count}")
            .font(size: 32, weight: .bold)
            .padding(24)

        Button("Increment") {
            count++
            haptic_light()
        }
    }
    .safe_area()
}

7. Add Rust business logic

// crates/app/src/vm.rs
#[ui_export]
pub struct HomeViewModel {
    #[ui_export(read)] pub greeting: String,
}

#[ui_export]
impl HomeViewModel {
    #[ui_export(writes = "greeting")]
    pub fn refresh(&mut self) {
        self.greeting = format!("Hello, {}!", local_time());
    }
}

8. Build for mobile

# iOS
cargo run -p flash-cli -- build --target ios app/screens/home.ui

# Android
cargo run -p flash-cli -- build --target android app/screens/home.ui

# Web
cargo run -p flash-cli -- build --target web app/screens/home.ui

9. Browse the docs locally

cargo run -p flash-cli -- docs
# Open http://localhost:3000

Quickstart

Build your first Flash mobile app in 5 minutes.

1. Prerequisites

  • Rust 1.75+ (rustup update)
  • For iOS: Xcode 15+, macOS
  • For Android: Android Studio, NDK r26+

2. Install the flash CLI

flash is not on crates.io yet — install from the repo:

git clone https://github.com/Anu-Code07/flash.git
cd flash
./scripts/install-flash.sh   # installs to ~/.cargo/bin

Ensure ~/.cargo/bin is on your PATH (zsh):

echo 'export PATH="$HOME/.cargo/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
flash help

Without a global install, prefix every command:

cargo run -p flash-cli -- create MyApp all
cargo run -p flash-cli -- dev --native ui/home.ui

3. Clone and run the counter

cd flash
flash run examples/counter/home.ui
# or: cargo run -p flash-cli -- run examples/counter/home.ui

Expected output: one SetProp + one Commit on tap — fine-grained reactivity confirmed.

4. Scaffold a new app

flash create MyApp all
cd MyApp
flash dev --native ui/home.ui

5. Create a screen

// app/screens/home.ui
screen Home {
    state count: Int = 0

    Column {
        Text("Count: ${count}")
            .font(size: 32, weight: .bold)
            .padding(24)

        Button("Increment") {
            count++
            haptic_light()
        }
    }
    .safe_area()
}

6. Add Rust business logic

// crates/app/src/vm.rs
#[ui_export]
pub struct HomeViewModel {
    #[ui_export(read)] pub greeting: String,
}

#[ui_export]
impl HomeViewModel {
    #[ui_export(writes = "greeting")]
    pub fn refresh(&mut self) {
        self.greeting = format!("Hello, {}!", local_time());
    }
}

7. Build for mobile

# iOS
cargo run -p flash-cli -- build --target ios app/screens/home.ui

# Android
cargo run -p flash-cli -- build --target android app/screens/home.ui

# Web
cargo run -p flash-cli -- build --target web app/screens/home.ui

8. Browse the docs locally

cargo run -p flash-cli -- docs
# Open http://localhost:3000

Project structure

my-app/
├── app/
│   ├── screens/          # .ui files
│   └── routes.ui         # navigation routes
├── crates/
│   ├── app/              # Rust view models (#[ui_export])
│   └── domain/           # business logic, no UI
├── ios/                  # thin Swift host
├── android/              # thin Kotlin host
└── flash.toml            # project config

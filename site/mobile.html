Mobile Development Guide

Flash is built mobile-first. iOS and Android are primary targets; Web follows.

Architecture on device

.ui source
    ↓ compile (on dev machine)
UI IR + dependency table + generated Rust
    ↓ link
Rust static lib (.a) / .so
    ↓ one FFI crossing per frame
iOS: Swift/UIKit host     Android: Kotlin/View host
    ↓
Native widgets on screen

iOS

ItemDetail
Targetaarch64-apple-ios
FFIC static lib + vtable
Frame driverCADisplayLink
WidgetsUILabel, UIButton, UIStackView → FlashLayoutView
AnimationCABasicAnimation / UIViewPropertyAnimator
HTTPURLSession via platform port
flash run ios              # Build + install simulator
flash run ios --device     # Physical device
flash build --release ios  # App Store build

Android

ItemDetail
Targetaarch64-linux-android
FFIJNI + direct ByteBuffer
Frame driverChoreographer
WidgetsTextView, MaterialButton, FlashFlexLayout
AnimationObjectAnimator / ViewPropertyAnimator
HTTPOkHttp via platform port
flash run android
flash build --release android

Mobile-specific STL

// Safe area for notch / home indicator
Column { ... }
    .safe_area()
    .padding(top: safe_area_top())

// Haptic feedback on tap
Button("Delete") {
    haptic_heavy()
    vm.delete()
}

// Keyboard-aware layout
TextField("Message")
    .keyboard_avoiding()

// Dark mode aware styling
Text("Hello")
    .color(is_dark_mode() ? .on_surface : .primary)

Project layout for a mobile app

my_app/
├── ui/screens/           # .ui files
├── crates/
│   ├── presentation/     # View models → .ui
│   ├── application/      # Use cases
│   └── infrastructure/   # HTTP, storage
├── platform/
│   ├── ios/              # Xcode project
│   └── android/          # Gradle project
└── flash.toml

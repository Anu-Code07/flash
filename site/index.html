UI that compiles.
Native on mobile.

Flash is a compiled cross-platform UI framework for iOS, Android, and Web. Write declarative .ui files, business logic in Rust, get native performance with zero JavaScript and no virtual DOM.

📱 iOS + Android + Web ⚡ Compile-time reactivity 🦀 Rust business logic 🎯 Native widgets 📦 C++-style STL
Get Started View Examples
🍎

iOS

UIKit via static lib + C FFI. CADisplayLink frame driver.

🤖

Android

View system via JNI + ByteBuffer. Choreographer vsync.

🌐

Web

WASM + DOM shim. Fine-grained updates, no virtual DOM.

Why Flash?

Compile-time reactivity

count → Text#1 is computed at compile time. One state change updates exactly one native property — no tree rebuild, no diff.

vs Flutter rebuild / Compose recompose

Native widgets

UILabel, TextView, MaterialButton — real platform views with free accessibility, text shaping, and OS integration.

vs custom renderers

Minimal runtime

Dependency graph is static. Runtime is slot storage + flush loop. Target: <100KB stripped core.

vs JS bridge / GC frameworks

Rich STL

C++-style standard library: collections, strings, math, mobile APIs, 30+ modifiers, design tokens, animation curves.

Built for mobile dev

Rust business logic

View models with #[ui_export]. Clean architecture: domain → application → presentation → .ui

Type-safe across boundary

Platform animations

.withAnimation compiles to Core Animation / Android Animator. Zero per-frame FFI during animation.

Compositor-only properties

Quick start

# 1. Clone & install CLI (adds `flash` to ~/.cargo/bin)
git clone https://github.com/Anu-Code07/flash.git
cd flash
./scripts/install-flash.sh

# Or run without installing:
# cargo run -p flash-cli -- create MyApp all

# 2. Create a mobile app
flash create MyApp all
cd MyApp

# 3. Dev + native hot reload
flash dev --native ui/home.ui
flash run --native ui/home.ui
// ui/screens/home.ui
screen Home {
    state count: Int = 0

    Column {
        Text("Count: ${count}")
            .font(size: 24, weight: .bold)
            .color(.primary)

        Button("Increment") {
            count++
        }
    }
}

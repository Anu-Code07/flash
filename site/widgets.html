Why Flash doesn't need 528 widgets

Modifiers replace styling widgets

Flutter's Padding, Center, ColoredBox, DecoratedBox → Flash modifier chains on a single node.

STL replaces npm packages

RN's safe-area-context, haptic-feedback, Share, navigation → built-in STL functions.

Native widgets, not a renderer

UILabel, TextView, MaterialButton — free accessibility, text shaping, OS integration.

Platform animators, not per-frame FFI

Core Animation / Android Animator for 60fps — beats both RN Reanimated and Flutter's rebuild model.

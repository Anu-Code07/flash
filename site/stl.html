Standard Library (STL)

C++ STL-inspired standard library built into every Flash app. Types, collections, string utilities, math, mobile APIs, modifiers, and design tokens — all available without imports.

Overview

The Flash STL is split into modules. Primitive types and UI builtins are always in scope. Collection/string/math functions are called from Rust view models or via Tier-1 imports. Mobile functions and modifiers are available in .ui handlers and modifier chains.

Design Tokens

.primary    .secondary   .surface    .background
.error      .on_primary  .on_surface .divider      .accent

Tokens resolve through the theme table. Light/dark switching updates the table and invalidates only nodes bound to token-valued properties.

Animation Curves

.linear
.ease_in
.ease_out

Curves compile to Core Animation (iOS), ObjectAnimator (Android), and WAAPI (Web). Zero per-frame FFI during animation.

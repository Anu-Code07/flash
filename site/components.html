Built-in Components

Flash ships a focused set of primitives mapped to native platform widgets. All components support modifier chains. See the Flutter & React Native comparison for full coverage analysis.

vs Flutter & React Native

React NativeFlutterFlash
Core components~12~528 (40 primitives)10 + 30 modifiers
RendererNative viewsSkia/ImpellerNative views
StylingStyleSheetWidget treeModifier chains
ListsFlatList, SectionListListView, GridViewList (keyed)
NavigationReact Navigation (npm)Navigatornavigate() STL
AnimationReanimated (npm)AnimationControllerPlatform animators
Safe areasafe-area-context (npm)SafeArea widget.safe_area() modifier

Flash covers 8/12 React Native core components today. Flutter's 528 widgets collapse to ~40 primitives — Flash's modifier system replaces ~200 of Flutter's styling widgets (Padding, Center, ColoredBox, etc.).

Examples

Text with modifiers

Text("Hello, Flash")
    .font(size: 28, weight: .bold)
    .color(.primary)
    .padding(horizontal: 16, vertical: 8)
    .safe_area()

Button with handler

Button("Continue") {
    haptic_light()
    navigate("/payment", orderId: order.id)
}

Image from URL

Image(product.imageUrl)
    .aspect_ratio(1.0)
    .border_radius(12)
    .fill_max_width()

TextField with binding

TextField("Search flights...")
    .keyboard_avoiding() {
    query = value
    vm.search(query)
}

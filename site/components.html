Built-in Components

Flash ships a focused set of primitives mapped to native platform widgets. All components support modifier chains.

Examples

Text with modifiers

Text("Hello, Flash")
    .font(size: 28, weight: .bold)
    .color(.primary)
    .padding(horizontal: 16, vertical: 8)
    .safe_area()

Button with handler

Button("Continue") {
    haptic_light()
    navigate("/payment", orderId: order.id)
}

Image from URL

Image(product.imageUrl)
    .aspect_ratio(1.0)
    .border_radius(12)
    .fill_max_width()

TextField with binding

TextField("Search flights...")
    .keyboard_avoiding() {
    query = value
    vm.search(query)
}

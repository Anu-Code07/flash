Examples

Real-world patterns for mobile apps. Each example shows the .ui screen and the Rust view model when needed.

Source files: examples/counter/, examples/flights/, examples/animation/, examples/navigation/

1. Counter (UI-only state)

Simplest app — all state in .ui. Fine-grained update: only the Text node refreshes on tap.

screen Home {
    state count: Int = 0

    Column {
        Text("Count: ${count}")
            .font(size: 32, weight: .bold)
            .padding(24)

        Row {
            Button("−") { count-- }
            Button("+") {
                count++
                haptic_light()
            }
        }
    }
}

IR output: slot0(count) → [op0 Text.text] — one SetProp per tap.

2. Counter with Rust view model

High score tracking — logic in Rust, UI in .ui.

// ui/screens/home.ui
use presentation::CounterViewModel

screen Home(vm: CounterViewModel) {
    Column {
        Text("Count: ${vm.count}")
        Text("Best: ${vm.high_score}").color(.accent)
        Button("Increment") { vm.increment() }
    }
}
// crates/presentation/src/counter_vm.rs
#[ui_export]
impl CounterViewModel {
    #[ui_export(writes = "count, high_score")]
    pub fn increment(&mut self) {
        self.count += 1;
        if self.count > self.high_score {
            self.high_score = self.count;
        }
    }
}

3. Flights — async data fetching

Full mobile pattern: loading, error, empty, list with keys.

use presentation::{FlightsViewModel, FlightsState}

screen Flights(vm: FlightsViewModel, query: String) {

    onLoad { await vm.load(query) }

    match vm.state {
        Loading -> Column {
            Loading()
            Text("Searching flights...").color(.muted)
        }
        Empty -> Column {
            Text("No flights found")
            Button("Try again") { await vm.load(query) }
        }
        Error(msg) -> Column {
            Text(msg).color(.error)
            Button("Retry") { await vm.load(query) }
        }
        Loaded(rows) -> List(rows) key: row.id { row in
            FlightCard(airline: row.airline, fare: row.fare)
        }
    }
}

4. Animated fade-in

screen Splash {
    state visible: Bool = false

    onLoad { visible = true }

    Column {
        Text("Flash")
            .opacity(visible ? 1.0 : 0.0)
            .with_animation(.ease_in_out(duration: 600))
    }
}

5. Platform-specific UI

screen Health {
    state steps: Int = 0

    Column {
        Text("Steps: ${steps}")

        platform ios {
            HealthKitChart(steps: steps)
        }
        platform android {
            GoogleFitChart(steps: steps)
        }
    }
}

6. Navigation

screen Checkout(order: Order) {
    Column {
        Text("Total: ${order.total}")
        Button("Pay now") {
            haptic_medium()
            navigate("/payment", orderId: order.id)
        }
        Button("Back") { navigate_back() }
    }
}
